How it works

  1. 01

    Watch

    The plugin tracks logic displays, canvases, sorters and illuminators, and groups neighbouring builds into a single piece of art.

  2. 02

    Render

    When the art changes, the group is rendered to an image off the main thread and sent to this server.

  3. 03

    Classify

    A ViT model rates the image SAFE, WARN or NSFW. SightEngine can optionally be chained to double check suspicious images.

    SafeWarnNSFW
  4. 04

    Act

    Depending on your policy, offending builds are deleted and refunded and the author is banned. Moderators get a Discord alert linking to the request page.

Install

Three steps on your Mindustry server, no restart dance.

Mindustry 159+Java 25

  1. Drop the jar

    Download nohorny-client.jar into your config/mods directory and start the server. SLF4MD is optional.

  2. Point it at this server

    The plugin uses https://nohorny.xpdustry.com/api by default. To use this instance, run:

    > config nohorny-api-endpoint https://nohorny.xpdustry.com/api

  3. Get alerts optional

    Add a Discord webhook to be notified when something gets flagged:

    > config nohorny-discord-webhook https://discord.com/api/webhooks/...

Every setting goes through the built-in config command of your server console. See the configuration reference for auto-mod policies and the rest.

Privacy

Images are only needed long enough for moderators to review an incident.

  • Safe images are never stored. Only flagged or unclassifiable images are kept, and only for a limited time.
  • Anyone with a link can purge an image. If a request page shows illegal content, report it and the image is deleted immediately.
  • No player identifiers. The plugin only sends the rendered image, never player names, UUIDs or player addresses.
